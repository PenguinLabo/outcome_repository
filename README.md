【前提】
本pyファイルはpyinstallerで変換して使用する。
Windowsタスクスケジューラーにpyinstallerで生成したexeをセットして、定期実行する。
サンプルコードのため、実際に個人PCで動かしている詳細値は伏せている。
サーバーに負荷をかけないよう、1日1回実行する。
実行前に、LINE Messaging APIの認証情報を環境変数に設定しておくこと（トークンのハードコーディングを避けるため）。
・LINE_ACCESS_TOKEN：チャネルアクセストークン（長期）
・LINE_USER_ID：通知先のユーザーID
【使用用途】
予約困難な宿の空室状況を取得するためのツール。
0時に定期実行し、予約が可能な場合はLINEのMessagingAPIを使用して、スマートフォンに空室日時と予約リンクを通知する。
前回時点で、既に同日の日にちの空室情報を送信していた場合はスキップする。（DBで情報管理）
